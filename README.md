# 休闲游戏策略看板

面向休闲游戏市场研究的交互式策略看板原型。项目将品类分类、游戏样本、市场变化、产品机制和研究进度组织为可浏览的分析路径，帮助研究者从「市场处于什么阶段」逐步追问「增长瓶颈是什么、哪些产品动作值得验证」。

> **数据说明**：本仓库是作品展示与产品原型，并非实时商业情报系统。页面同时包含公开资料整理、第三方估算口径的示例和明确标注的模拟数据；部分页面仅展示分析框架。Sensor Tower API、数据库自动更新与定时异动监测尚未接入。请勿将演示数字当作已验证的市场结论。

## 核心内容

- **品类研究**：按照市场阶段和研究优先级展示 12 个重点品类，对成熟三消、二合及潜力品类采用不同的分析深度。
- **游戏样本库**：整理 161 款游戏，支持按品类、产品形态及候选分组浏览与检索。
- **市场与机制视图**：将结果指标、增长驱动和产品机制分层呈现，讨论留存、LiveOps、内容供给、变现与买量等问题。
- **策略验证原型**：展示从指标异动、策略节点到后续表现的分析链路，并保留替代解释与证据强度。
- **研究进度**：明确区分已完成的原型页面、仍需补充的数据和规划中的功能。

## 我的工作

我负责把策略团队的研究需求拆解为品类分类、指标框架、页面结构和数据需求，并通过多轮 Prompt 与 AI Agent 协作完成资料整理、原型实现和迭代；本人核对研究口径、样本分类、数据标识与最终表达。该看板是交互式原型，不能视为已上线的实时数据产品。

## 技术栈

TypeScript、React、Next.js、vinext、Cloudflare Workers。仓库保留项目中的可选 D1/Drizzle 示例结构，但看板当前不依赖已上线的 D1 数据库。

## 资料与使用边界

研究观点基于公开资料和原型阶段的分析整理；涉及第三方平台的数值均应按其原有估算口径理解。部分图表使用模拟数据来展示未来产品形态，相关页面已标注。游戏名称、商标及图标归各自权利人所有，仅用于产品识别与非商业性作品展示。
